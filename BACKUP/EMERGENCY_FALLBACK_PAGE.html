Limpeza de Cache

Se está com problemas para fazer login, clique no botão abaixo para limpar o cache da aplicação.

💡 Método Manual (se o botão não funcionar)

Windows / Linux:

  1. Carregue Ctrl + Shift + Delete
  2. Selecione "Última hora" ou "Tudo"
  3. Marque "Cookies" e "Cache"
  4. Clique em "Limpar dados"
  5. Volte à página e faça login

Mac:

  1. Carregue Cmd + Shift + Delete
  2. Siga os mesmos passos acima

OU simplesmente:

  1. Carregue Ctrl + F5 (ou Cmd + Shift + R no Mac)
  2. Faça login novamente
