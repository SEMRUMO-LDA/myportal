📱 Como Gerar Token para Qualquer Utilizador

Token = Base64 encode de: userId-phone

Exemplo:

  • User ID: 73
  • Phone: 911100707
  • String: "73-911100707"
  • Token: NzMtOTExMTAwNzA3
JavaScript:
const token = btoa(`${userId}-${phone}`);

🔧 Debugging

Se aparecer "Token inválido", verificar:

  1. ✅ Token está em formato Base64 correto
  2. ✅ String decodificada tem formato: "userId-phone"
  3. ✅ userId é um número válido
  4. ✅ phone corresponde ao userId na base de dados

Após a correção: Mesmo com token inválido, deve permitir picar!
