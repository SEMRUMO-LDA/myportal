## 🔗 Como Funciona

### Para o Colaborador:
1. **Recebe o seu link único** por WhatsApp/Email
2. **Guarda o link** nos favoritos do telemóvel
3. **Clica no link** para abrir a página de picagem
4. **Clica em "Entrada"** ou **"Saída"**
5. **Pronto!** Picagem registada instantaneamente

### Características:
- ✅ **Sem login necessário** - Link já identifica o colaborador
- ✅ **Funciona em qualquer dispositivo** - Telemóvel, tablet, PC
- ✅ **Interface simples** - 2 botões grandes e claros
- ✅ **Relógio em tempo real** - Mostra a hora atual
- ✅ **Confirmação visual** - Mensagem de sucesso/erro
- ✅ **Última picagem** - Mostra o último registo

## 📱 Sistema NFC/QR Code (Opcional)

### Para implementar NFC no escritório:

#### Opção 1: Tags NFC Individuais
1. **Comprar tags NFC** (cerca de €0.50 cada)
2. **Programar cada tag** com o link do colaborador
3. **Colar no cartão** do colaborador
4. **Colaborador aproxima o cartão** do telemóvel/tablet

#### Opção 2: Terminal NFC Central
1. **Colocar tablet/PC** na entrada do escritório
2. **Abrir página `terminal-nfc.html`**
3. **Colaborador aproxima cartão NFC**
4. **Sistema identifica e regista** automaticamente

#### Opção 3: QR Code
1. **Imprimir QR Code** de cada colaborador
2. **Colar no crachá/cartão**
3. **Mostrar ao terminal** para picar

## ⚠️ Considerações de Segurança

### Implementado:
- ✅ **Token único** por colaborador (hash SHA-256)
- ✅ **Link pessoal** - identifica univocamente
- ✅ **Sem passwords** - mais conveniente
- ✅ **Registo de método** - identifica como foi feita a picagem

### Recomendações:
1. **Não partilhar links** entre colaboradores
2. **Renovar links** periodicamente (mensal/trimestral)
3. **Monitorizar uso** para detetar anomalias
4. **Desativar links** de colaboradores inativos
